# Library Management System

## Overview

The **Library Management System** is a backend-oriented application developed in **Java**, designed to simulate the core operations of a library, including book management, user handling, and loan control.

This project was built with a strong focus on **backend fundamentals**, clean object-oriented design, and business rule implementation. It reflects my ability to design structured systems, apply backend logic, and write maintainable and scalable code.

---

## Project Purpose

The main goals of this project are to:

- Strengthen backend development fundamentals using Java;
- Apply **Object-Oriented Programming (OOP)** principles in real-world scenarios;
- Work with in-memory data structures to manage application state;
- Model business rules and domain entities clearly and efficiently.

---

## Features

- Book registration and listing;
- User registration and listing;
- Loan management and control;
- Business rule validations (availability, existing records, etc.);
- Modular structure prepared for future scalability.
